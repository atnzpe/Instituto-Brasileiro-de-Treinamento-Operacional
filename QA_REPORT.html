01 Resumo executivo

Contrato de veredito: APROVADO somente com zero P0/P1 em fluxos críticos, mobile utilizável, LCP < 2.5s (ou justificativa), 404 real e menu acessível por teclado.
Resultado: FALHOU — múltiplos P1 confirmados.

O site sobe e comunica a marca com estética tática consistente. As páginas principais (/, /areas-de-atuacao, /quem-somos, /contato) respondem HTTP 200. A qualidade atual, porém, não está pronta para aprovação.

  1. Performance crítica — LCP 3,8s · TTFB ~3,6s · ~12,2 MB no load (PNGs 1,5–2,6 MB).
  2. Menu mobile inutilizável — ícone ~25×25px, cor quase preta no fundo escuro.
  3. Teclado quebrado no menu — Áreas / Quem somos / Contato com tabIndex: -1.
  4. Hero duplicado — título da marca sobreposto no desktop.
  5. Soft 404 — URL inexistente redireciona para home com 200.
  6. SEO frágil — sem meta description, home sem H1, OG incompleto.
